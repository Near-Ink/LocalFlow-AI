对话引擎未连接

LocalFlow 的对话与 Agent 能力由 DeepSeek Harness（dsh） 提供，当前未在 127.0.0.1:8080 检测到 dsh 服务。

  1. 安装并启动 dsh（任选其一）： 
    npx @deepseek-ai/dsh --profile web
    若已克隆仓库并在 dsh-poc/ 下装好依赖，可直接运行： 
    node_modules/.bin/dsh --profile web
    （注意：dsh-poc/ 的 package.json 没有 dev 脚本，pnpm run dev 会报错。）
  2. 确认 dsh 已监听 8080 后，点击下方「重新连接」。

未安装 dsh 也可使用「部署模型 / 硬件监控 / 对外 API / 设置」等本地功能。
